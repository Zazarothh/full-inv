# Full Inv

Inventory full? Drop the junk.

Highlights the lowest value item when your inventory hits 28 slots. Works with GE prices or High Alch values for ironmen.

## Features

- Red box highlight on lowest value item when inventory fills
- Chat message showing item name and value
- Ironman Mode: Use High Alch value instead of GE
- Persistent highlight option (set duration to 0)
- Clears highlight immediately when you drop the item

## Config

- Enable Highlight (default: on)
- Highlight Duration in seconds (default: 3, set 0 for persistent)
- Show Chat Message (default: on)
- Include Untradeables (default: on)
- Ironman Mode (default: off)
